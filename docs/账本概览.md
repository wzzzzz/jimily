# 账本概览

`/user/overview` 是登录用户的账本月度概览页，用于一屏查看所选月份的收入、支出、净收入、预算进度、最近流水、支出构成与近 6 个月趋势，并可直接记一笔或编辑最近流水。

## 入口

- 桌面端：侧栏「主要功能」→「概览」
- 移动端：底栏第 1 项「概览」（底栏共 5 项：概览、预算、分析、日历、流水）

## 页面能力

| 区块 | 说明 | 数据来源 |
| --- | --- | --- |
| 月份切换 | 默认本地当前月；可查看历史月份；不可进入未来月份；非当前月时显示「回到本月」 | 前端本地时间 |
| 本月汇总 | 总收入、总支出、净收入、不计收支 | `POST /api/entry/flow/page` 的 `totalIn` / `totalOut` / `notInOut` |
| 本月预算 | 预算、已用、剩余、进度条；无预算时展示「去设置预算」；超支时警示色与「已超支」 | `POST /api/entry/budget/all` + 实时 `totalOut` |
| 最近流水 | 所选月份最近 5 条；点击打开现有流水编辑弹窗；「查看全部」进入流水页 | `POST /api/entry/flow/page`（`pageSize: 5`） |
| 支出构成 | 按 `industryType` 聚合支出，最多前 6 类，其余合并为「其他」 | `POST /api/entry/analytics/common` |
| 近 6 个月趋势 | 以所选月份为终点的 6 个月收入/支出柱状图，缺失月份补 0 | `POST /api/entry/analytics/month` |
| 记一笔 | 复用现有 `FlowEditDialog`，默认日期为本地今天；保存后自动刷新概览 | `POST /api/entry/flow/add` |

## 数据口径

- 收入、支出金额取绝对值；净收入 = 总收入 − 总支出；不计收支不参与净收入。
- 预算「已用」取所选月份实时 `totalOut`，**不使用** `Budget.used` 快照。预算页「刷新额度」后可能与本页短暂不同，属预期差异。
- 预算进度 = 已用 / 预算；预算为空或 0 时展示「未设置预算」，不做除零。
- 同一用户同一月份存在多条预算记录时，按接口返回顺序取第一条（与现有预算页一致）。
- 支出构成「其他」为多分类合并项，不支持点击下钻。
- 月份切换存在请求竞态保护：只应用最新一次请求结果；切换期间展示加载态，不混用旧月份数据。

## 实现约定

- 页面使用 `public` 布局与 `auth` 中间件；接口由服务端 JWT 隔离用户，页面不传递 `userId`。
- 复用现有语义色（`bg-surface`、`border-border`、`text-foreground`、`primary-*`）与 ECharts 组件，不新增图表库或 UI 库。
- `ChartsCommonPie` 新增可选 `maxItems` / `emptyText`；`MonthBar` 新增可选 `startDay` / `endDay` / `months` / `emptyText`；不传时保持原有分析页行为。
- 本次不新增数据库表/字段/迁移，不新增或修改后端接口。
