# 账本概览 — E2E 测试用例

> 对应需求：`docs/需求规格书（Spec）/产品 Spec.md`（REQ-001～010）
> 页面：`/user/overview`
> 仓库现状：无 E2E 测试框架与脚本；本文件为可执行的用例清单（含自动化实现建议），本次不新增测试框架依赖。

## 1. 环境与前置

| 项 | 要求 |
| --- | --- |
| 运行环境 | `pnpm install` + `pnpm dev`（端口 9090），PostgreSQL 可用，`.env` 已按 `.env.example` 配置 |
| 浏览器 | Chromium（桌面 1440×1000、移动 375×812） |
| 账号 | 用户 A、用户 B（用于数据隔离），均能登录 |
| 初始数据 | 用户 A：当前月至少 7 笔支出（覆盖 7 个不同 `industryType`）、2 笔收入、1 笔不计收支、1 条当前月预算、1 条历史月流水；用户 B：独立流水与预算 |
| 断言口径 | 金额两位小数；收入/支出取绝对值；净收入 = 总收入 − 总支出；预算已用 = 所选月实时 `totalOut` |

## 2. 核心路径

| ID | 优先级 | 关联 REQ | 前置 | 步骤 | 预期结果 |
| --- | --- | --- | --- | --- | --- |
| E2E-OVW-001 | P0 | REQ-001 | 用户 A 已登录 | 访问 `/user/overview` | 渲染概览页；默认当前月；侧栏「概览」选中；无控制台报错 |
| E2E-OVW-002 | P0 | REQ-003 | 同上 | 对比概览汇总与 `/user/flows` 顶部统计（同月） | 总收入、总支出、净收入、不计收支四项数值一致；净收入 = 收入 − 支出 |
| E2E-OVW-003 | P0 | REQ-005 | 同上 | 查看「最近流水」 | 展示 5 条；按日期倒序、同日按 id 倒序；显示日期/名称或分类/账户/金额；金额右对齐 |
| E2E-OVW-004 | P1 | REQ-004 | 当前月有预算 | 查看「本月预算」 | 展示预算、已用、剩余、进度百分比；已用 = 汇总总支出；进度 = 已用/预算 |
| E2E-OVW-005 | P1 | REQ-006 | 当前月支出覆盖 7 个分类 | 查看「支出构成」 | 环形图最多 6 类 + 「其他」；「其他」= 第 7 类及以后金额之和；占比合计 100% |
| E2E-OVW-006 | P1 | REQ-007 | 当前月及前 5 个月有流水 | 查看「近 6 个月趋势」 | 横轴连续 6 个月且以所选月为终点；缺失月份为 0；收入/支出双柱 |
| E2E-OVW-007 | P0 | REQ-008 | 已登录 | 点击「记一笔」→ 填写金额/类型/分类 → 保存 | 打开「新增流水」弹窗，默认日期为本地今天；保存成功 Toast「新增成功!」；概览汇总与最近流水自动刷新 |
| E2E-OVW-008 | P0 | REQ-005 | 最近流水非空 | 点击一条最近流水 → 修改金额 → 保存 | 打开「修改流水」弹窗并回填；保存成功 Toast「更新成功!」；概览刷新 |
| E2E-OVW-009 | P0 | REQ-002 | 已登录 | 点击上一月 | 月份标签减 1；汇总/预算/最近流水/构成/趋势按新月份刷新；趋势终点同步 |
| E2E-OVW-010 | P0 | REQ-002 | 处于历史月 | 点击「回到本月」 | 恢复当前月并刷新 |
| E2E-OVW-011 | P0 | REQ-002 | 处于当前月 | 检查「下个月」按钮 | 按钮禁用；点击无效果，不会进入未来月份 |
| E2E-OVW-012 | P0 | REQ-009 | 桌面端已登录 | 点击侧栏「概览」 | 跳转 `/user/overview`，菜单项选中 |
| E2E-OVW-013 | P0 | REQ-009 | 移动端 375px 已登录 | 点击底栏「概览」 | 跳转 `/user/overview`；底栏 5 项均可见、不重叠、不遮挡内容；当前项高亮 |

## 5. 自动化实现建议（Playwright，后续引入时使用）

> 本次不新增测试框架依赖；以下选择器基于页面现有可访问性属性与文案，便于后续落地。

| 目标 | 建议定位 |
| --- | --- |
| 页面标题 | `getByRole('heading', { name: '账本概览' })` |
| 上一月/下一月 | `getByRole('button', { name: '上个月' })` / `getByRole('button', { name: '下个月' })` |
| 回到本月 | `getByRole('button', { name: '回到本月' })` |
| 记一笔 | `getByRole('button', { name: '记一笔' }).first()` |
| 汇总卡 | `getByText('总收入')` 所在卡片内断言数值 |
| 预算进度 | `getByRole('progressbar', { name: '预算使用进度' })`，断言 `aria-valuenow` |
| 最近流水 | `getByRole('heading', { name: '最近流水' })` 所在 section 内 `button` 列表 |
| 支出构成/趋势 | `getByRole('heading', { name: '支出构成' })` / `getByRole('heading', { name: '近 6 个月趋势' })` |
| 弹窗 | `getByRole('heading', { name: '新增流水' })` / `{ name: '修改流水' }` |
| 接口失败注入 | Playwright `page.route('**/api/entry/flow/page', route => route.abort())` |
| 深色模式 | 侧栏主题切换按钮（文案「深色模式」/「浅色模式」） |
