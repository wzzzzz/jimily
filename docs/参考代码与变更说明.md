现有 Jimily 已具备流水、资金账户、预算、分析、分类、日历、借出、API 令牌与 Jimi 助手；缺少统一的本月概览页。本次增量：

| 概览模块 | 复用现有能力 | 数据来源 |
| --- | --- | --- |
| 汇总卡（总收入/总支出/净收入/不计收支） | `FlowsStatistics` 视觉与文案 | `POST /api/entry/flow/page` 的 `totalIn`、`totalOut`、`notInOut` |
| 预算进度 | `Budget` 模型与预算页 | `POST /api/entry/budget/all` |
| 最近流水 | 流水页表格行样式与 `FlowEditDialog` | `POST /api/entry/flow/page`（`pageSize: 5`） |
| 支出构成 | 分析页 `ChartsCommonPie` | `POST /api/entry/analytics/industryType`（`flowType=支出`） |
| 近 6 个月趋势 | 分析页 `MonthBar` / `analytics/month` | `POST /api/entry/analytics/month` |
| 快速记账 | 现有 `FlowEditDialog`、`flow/add` | 通过 `showFlowEditDialog`、`dialogFormTitle`、`selectedFlow` 复用 |

## 4. 关键实现说明

### 4.1 月份与日期边界

- 月份键 `YYYY-MM`；当前月由本地时区 `new Date()` 计算。
- 上/下月通过 `new Date(year, month - 1 + delta, 1)` 计算，避免跨年问题。
- 月份起止：`YYYY-MM-01` 至 `YYYY-MM-<lastDay>`；与现有 `parseDateBoundary` 兼容。
- 下月不得晚于当前月；历史月份可查看。

### 4.2 汇总口径

- `totalIn`、`totalOut`、`notInOut` 直接使用 `flow/page` 返回值。
- 净收入 = `totalIn - totalOut`；不计收支不参与净收入。
- 金额展示保留两位小数，使用 `toLocaleString('zh-CN')`；生产实现可复用现有格式化工具。

### 4.3 预算

- `budget/all` 返回所有月份预算，按 `month === selectedMonth` 匹配。
- 进度 = `totalOut / budget`；`budget` 为空或 0 时展示「未设置预算」，避免除零。
- 超支时使用红色进度条与「已超支」文案。
- 当前月可展示「剩余天数 / 日均可用」；历史月展示「该月已结束」。

### 4.4 最近流水

- `flow/page` 请求：`startDay`、`endDay`、`pageNum: 1`、`pageSize: 5`。
- 服务端按 `day desc, id desc` 排序，并返回 `account` 关联名称。
- 点击行打开 `FlowEditDialog`，回填流水；保存成功后 `successCallback` 重新加载。
- 无数据时展示空态与「记一笔」。

### 4.5 支出构成与趋势

- 支出构成：`analytics/industryType` 返回 `{ type, inSum, outSum, zeroSum }`；筛选 `flowType=支出`，按 `outSum` 降序。
- 趋势：`analytics/month` 返回 `{ type: "YYYY-MM", inSum, outSum, zeroSum }`；按月份升序。
- 原型使用轻量 SVG 模拟环形图与双柱趋势；实际实现优先复用 `ChartsCommonPie` 与 `MonthBar`。
- `MonthBar` 当前可能展示全部月份；若需严格限制近 6 个月，开发节点可扩展 props 或在页面内使用 `analytics/month` 数据渲染。

### 4.6 快速记账

复用 `FlowEditDialog`：

```ts
import { showFlowEditDialog } from '~/utils/flag';

const dialogFormTitle = ref('新增流水');
const selectedFlow = ref({});

const openCreateDialog = () => {
  dialogFormTitle.value = '新增流水';
  selectedFlow.value = {};
  showFlowEditDialog.value = true;
};
```

保存成功后由 `FlowEditDialog` 内部调用 `flow/add` 或 `flow/update`，并通过 `successCallback` 刷新概览。不新增表单、不新增接口。

### 4.7 权限与数据隔离

- 页面使用 `middleware: ['auth']`；接口由 `server/middleware/auth.ts` 校验 JWT。
- 服务端从 JWT 取 `userId`，页面不传 `userId`。
- 不读取/展示 `.env`、`data/`、密钥或数据库备份。

## 6. 已知限制与假设

- 原型使用 Mock 数据；实际页面以现有接口返回为准。
- 原型使用原生 `input[type=date]`；实际实现应复用 `UiDatePicker`，保持现有表单体验。
- 根路由 `/` 仍跳转 `/user/jimi`；本迭代不改变默认落地页。
- 移动端底栏由 4 项调整为 5 项；需在真机/窄屏验证不重叠。
- `MonthBar` 是否严格限制 6 个月待开发节点确认。
- 账户余额卡未纳入首版概览；账户信息仍通过 `/user/accounts` 查看。
- 未新增埋点；后续如需评估概览使用情况，需按现有观测规范另行设计。
